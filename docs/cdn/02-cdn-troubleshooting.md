# CDN 下载链路故障排查手册

> 场景：用户反馈下载慢、下载失败、文件损坏、部分地域不可用。
> 方法：**按链路逐段排除**：客户端 → DNS → 网络 → 边缘节点 → 回源 → 源站。

## 1. 排查前置信息（先问清楚）

| 信息 | 说明 |
| --- | --- |
| 影响范围 | 全部用户 / 部分地域 / 部分运营商 / 单用户 |
| 时间窗口 | 从什么时候开始，是否与发布/变更重合 |
| 复现信息 | 具体 URL、文件大小、错误码、耗时 |
| 环境信息 | 客户端类型、网络环境（公司内网/家宽）、地区 |

## 2. 分级判断（快速分诊）

```text
全部用户异常   → 域名/DNS/源站/全节点问题
部分地域异常   → DNS 调度 / 该地域节点 / 运营商链路
单用户异常     → 客户端网络、本地代理、浏览器缓存
特定文件异常   → 该文件缓存损坏、回源失败、预热遗漏
特定时段异常   → 发布变更、流量高峰、源站过载
```

## 3. 逐段排查步骤

### 3.1 客户端与网络

```bash
# 分段计时：DNS → TCP → TLS → TTFB → 总时长
curl -w 'dns:%{time_namelookup} tcp:%{time_connect} tls:%{time_appconnect} ttfb:%{time_starttransfer} total:%{time_total}\n' -o /dev/null -s <URL>

# 下载速度测试（大文件）
curl -o /dev/null -s -w 'speed:%{speed_download} size:%{size_download}\n' <URL>
```

TTFB 长 → 服务端/网络路由问题；TTFB 正常但下载慢 → 带宽/限速/节点负载问题。

### 3.2 DNS 调度

```bash
dig <域名> @<本机DNS>
dig <域名> @8.8.8.8          # 对比公共 DNS 结果是否一致
```

- 不同地域解析到不同 IP：正常（就近调度）。
- 解析到已下线/异常节点 IP：调度系统未摘除，需人工摘除 + 检查健康检查。
- 全局解析结果异常：检查域名 NS、TTL、调度系统配置。

### 3.3 边缘节点

```bash
# 命中节点后直接测试该节点
curl -I http://<节点IP>/<path> -H "Host: <域名>"
curl -I <URL> -H "X-Forwarded-For: <测试IP>"   # 部分 CDN 支持指定来源模拟
```

检查点：

- 响应头 `X-Cache: HIT/MISS`（或等价字段）判断命中情况。
- `Content-Length` 与源站是否一致（不一致 = 缓存损坏/被截断）。
- 节点磁盘是否写满、连接数是否打满（`ss -s`、`iostat`、节点监控）。
- 节点限速配置是否异常（下载速率被限制到某固定值）。

### 3.4 回源链路

```bash
# 绕过 CDN 直连源站测试
curl -w '...' -o /dev/null -s https://<源站>/<path>
```

- 直连源站快而 CDN 慢 → 问题在节点或回源缓存策略。
- 直连源站也慢 → 源站性能/网络问题，转源站排查。
- 回源失败率高 → 看源站连接数、回源限流、源站 WAF/防火墙、回源 Host 配置。

### 3.5 源站

- 源站负载：CPU/内存/磁盘 IO/带宽（`top`、`iostat`、`sar -n DEV`）。
- 对象存储场景：检查 Bucket 是否欠费/被限流（403/429）、跨区复制状态、版本管理。
- 文件服务器场景：检查文件是否存在、权限、软链、磁盘满。

## 4. 文件损坏 / 校验失败

1. 对比 CDN 返回的 `Content-Length` / `ETag` 与源站是否一致。
2. 下载后对比文件哈希（MD5/SHA256）与源站文件。
3. 检查是否为**断点续传**导致：客户端 Range 请求与缓存文件不匹配。
4. 检查节点磁盘坏块/写满导致缓存截断 → 刷新该文件重新缓存。
5. 大文件分片场景：检查分片序号与合并逻辑，必要时客户端重试。

## 5. 高并发 / 大包场景专项

- **下载慢但连接正常**：节点带宽打满 → 查看节点带宽监控、限速策略、增加节点或限流。
- **连接建立失败**：连接数打满 → 调大节点连接数、启用 keep-alive、客户端限制并发。
- **回源打满**：命中率低 + 大包 → 提升预热、加大缓存、分级缓存。
- **源站雪崩**：回源重试风暴 → 边缘回源熔断、源站限流、排队。

## 6. 排查时间线模板

```text
10:00  收到反馈：华东用户下载 P4 大包失败率上升
10:05  确认影响范围：华东部分节点、特定大文件
10:08  DNS 解析检查：解析正常，指向华东节点 A/B
10:12  直连测试：节点 A 下载 10KB/s，节点 B 正常
10:15  节点 A 检查：磁盘 IO util 100%，日志显示缓存写满截断
10:20  摘除节点 A 流量，刷新受影响文件，恢复
10:30  根因：节点 A 磁盘容量不足 + 预热任务集中写入
11:00  复盘：容量水位告警缺失、预热无错峰、增加磁盘告警与预热限速
```

## 7. 高频结论速查

| 症状 | 首选动作 |
| --- | --- |
| 全部用户下载慢 | 查源站负载与回源链路、节点带宽总水位 |
| 部分地域慢/失败 | 查该地域节点健康、DNS 调度、运营商链路 |
| 单文件失败 | 刷新该文件缓存，对比源站哈希 |
| 下载中断/损坏 | 查 Range 续传、Content-Length、缓存截断 |
| 回源失败率高 | 查源站限流、回源超时配置、防火墙 |
| 发布后异常 | 先查发布清单、预热任务、缓存刷新是否完成 |
