# 高频故障速查表

> 面向 SRE 日常运维与应急处理的高频故障清单：症状 → 排查 → 处置。

## 应用与网关

| 症状 | 排查 | 处置 |
| --- | --- | --- |
| 502 Bad Gateway | 上游进程、端口、健康检查、连接数 | 重启/摘除异常上游、扩容 |
| 504 超时 | 上游处理慢（SQL、阻塞）、超时配置 | 优化上游、调大超时、限流 |
| 499（客户端断开） | 上游响应慢，客户端先超时 | 优化上游 P99、客户端超时对齐 |
| 大量 429 | 限流阈值过低/被刷 | 分析来源、调阈值、加防护 |
| 大量 500 | 应用异常 | 看日志/异常率、回滚发布 |

## 数据库

| 症状 | 排查 | 处置 |
| --- | --- | --- |
| 连接打满 | PROCESSLIST、连接池 | Kill 慢会话、修连接池、扩容 |
| 主从延迟 | 大事务、从库负载 | 拆事务、优化从库、并行复制 |
| 慢查询激增 | 慢日志 + EXPLAIN | 加索引、改 SQL、限流 |
| 死锁 | `SHOW ENGINE INNODB STATUS` | 统一锁顺序、重试 |
| 磁盘满 | 日志/Binlog/临时文件 | 清理 + 扩容 + 保留策略 |

## 缓存

| 症状 | 排查 | 处置 |
| --- | --- | --- |
| 缓存穿透 | 空 key 打 DB | 空值缓存、布隆过滤器 |
| 缓存击穿 | 热点 key 过期 | 互斥锁重建、逻辑过期 |
| 缓存雪崩 | 大量 key 同时过期 | TTL 抖动、多级缓存 |
| Redis 卡顿 | 大 key、慢命令 | SLOWLOG、UNLINK、拆分 |
| 内存暴涨 | 无 TTL、大 key | 设置 TTL、清理、maxmemory |

## Kubernetes

| 症状 | 排查 | 处置 |
| --- | --- | --- |
| Pending | describe + 事件 | 资源/污点/PVC |
| CrashLoop | logs --previous | 配置/依赖/探针 |
| OOMKilled | limits 与用量 | 调参、查泄漏 |
| Service 不通 | endpoints/readiness/DNS | 修标签/探针/网络 |
| Node NotReady | kubelet/磁盘/内存/运行时 | 恢复节点、排空重建 |

## 网络

| 症状 | 排查 | 处置 |
| --- | --- | --- |
| DNS 解析慢/失败 | dig +trace、多 DNS 对比 | 修 NS/TTL、换 DNS |
| TCP 连接超时 | ping/telnet/抓包 | 防火墙、路由、端口 |
| TIME_WAIT 多 | 短连接频繁 | keep-alive、连接池 |
| 连接被拒 | ss -lntp | 启服务、修监听 |

## CDN / 下载

| 症状 | 排查 | 处置 |
| --- | --- | --- |
| 命中率低 | 缓存键/Header/调度 | 调缓存策略、版本化 |
| 回源失败率高 | 源站限流/超时/防火墙 | 调超时重试、熔断 |
| 下载损坏 | Content-Length/哈希 | 刷新缓存、校验 |
| 部分地域异常 | DNS 调度/节点健康 | 摘除节点、切调度 |

## 云平台

| 症状 | 排查 | 处置 |
| --- | --- | --- |
| 实例失联 | 控制台/VNC、安全组、系统状态 | 重启、安全组恢复 |
| 磁盘满 | 云监控 + df | 清理、扩容 |
| 账单异常 | 预算告警、Cost Explorer | 关停闲置、限流 |
| 权限报错 | IAM/RAM 策略 | 最小权限修正 |
