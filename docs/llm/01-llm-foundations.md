# LLM 基础知识

> 面向工程视角的 LLM 概念梳理：原理、训练、推理、能力边界与评估。不涉及具体厂商立场，只讲通用知识。

## 1. 什么是 LLM

大语言模型（Large Language Model）是基于 Transformer 架构的神经网络模型，核心任务是从海量文本中学习语言规律，通过**自回归**方式逐个预测下一个 token，从而生成文本。

关键概念：

- **Token**：文本切分的基本单位（词或子词），模型按 token 计数与定价。
- **自注意力（Attention）**：让每个 token 关联上下文中的其他 token，是 Transformer 的核心机制。
- **上下文窗口（Context Window）**：模型单次能处理的 token 上限（几 K 到百万级不等）。
- **temperature / top-p**：控制输出随机性的采样参数；temperature 越高输出越多样，越低越确定。

## 2. 训练管线

一个生产级 LLM 通常经过三阶段：

```text
预训练（Pre-training）
  → 海量无标注文本，任务：预测下一个 token
  → 得到「基础模型」，知识广但不会对话
  ↓
监督微调（SFT）
  → 用高质量「指令-回答」数据对齐人类期望格式
  → 学会遵循指令、回答问题
  ↓
偏好对齐（RLHF / DPO 等）
  → 用人类偏好数据优化
  → 让输出更符合有用、诚实、无害的原则
```

理解这条管线很重要：模型的「知识」来自预训练语料（有截止日期），「听话程度」来自后两阶段。这解释了模型的两个典型问题：知识有截止、可能幻觉。

## 3. 推理与部署

### 推理链路

```text
输入文本 → Tokenize → 前向计算 → 生成 token（循环）→ 输出文本
```

生成是逐 token 的，因此：

- **首 token 延迟**：处理输入并产生第一个输出 token 的时间。
- **吞吐（tokens/s）**：单位时间生成的 token 数。
- **KV Cache**：缓存历史 token 的键值，避免重复计算；显存占用随上下文增长。

### 部署要点

- **GPU 选型与显存**：模型参数（如 70B 参数 FP16 约 140GB）决定所需显存与卡数。
- **量化**：FP16 → INT8/INT4，减少显存与带宽，代价是精度损失。
- **推理框架**：vLLM（PagedAttention 提升吞吐）、TensorRT-LLM、SGLang 等。
- **批处理（batching）**：合并多个请求一起推理，显著提升吞吐、摊薄成本。
- **延迟 vs 吞吐取舍**：交互场景要低延迟，离线批量任务追求高吞吐。

## 4. 能力与边界

### 能做

- 语言理解与生成、翻译、摘要、代码生成与解释。
- 遵循复杂指令、多轮对话、结构化输出。
- 结合工具（检索、调用 API、执行代码）完成任务。

### 边界（工程上必须知道）

| 边界 | 说明 | 应对 |
| --- | --- | --- |
| 幻觉 | 编造不存在的知识/事实 | RAG 提供依据、要求引用、人工复核 |
| 知识截止 | 训练数据有时间点 | 结合实时检索补充 |
| 上下文有限 | 超长内容被截断或遗忘 | 摘要、分块、检索 |
| 无真实推理 | 看似合理但可能错 | 复杂任务拆分 + 验证 |
| 成本与延迟 | 复杂任务 token 消耗大 | 模型分级路由、缓存、精简 prompt |
| 不可解释 | 无法完全解释输出原因 | 记录输入输出、加审计 |

## 5. 评估

### 模型层评估

- 通用 benchmark：MMLU（知识）、HumanEval（代码）、GSM8K（数学）等。
- 用途：横向对比模型能力；局限性：与真实业务场景有差距。

### 应用层评估（更重要）

- **Golden Set**：一批代表性输入 + 期望输出。
- **自动评估**：规则匹配、LLM-as-judge（用模型打分）。
- **人工评估**：小样本人工打分，质量最可靠。
- **指标**：准确率、相关性、格式合规率、幻觉率、成本/延迟。

工程实践：把评估集纳入 CI，模型升级或 prompt 改动时跑回归，防止「优化一个问题、回归十个问题」。

## 6. 安全与合规

- **提示注入（Prompt Injection）**：外部输入里藏指令试图劫持模型——对不可信内容做隔离与提示。
- **越狱（Jailbreak）**：绕过安全对齐的输入构造——需要输入过滤与护栏。
- **数据泄露**：不要把敏感数据放进 prompt 或训练集；输出侧做 PII 脱敏。
- **内容安全**：输入输出双向内容审核（moderation）。
- **审计**：记录请求、输出、工具调用，支撑追溯与合规。
