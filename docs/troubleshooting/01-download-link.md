# 大包下载链路全链路排查

> 适用：GB 级安装包/版本包下载慢、失败、损坏的端到端排查。与 CDN 排查手册配合使用。

## 1. 链路模型

```text
客户端（下载器/分片并发/断点续传）
  → DNS（域名解析/调度）
  → 网络（TCP/TLS/运营商链路）
  → CDN 边缘节点（缓存命中/限速/带宽）
  → CDN 中心/二级节点（分级缓存）
  → 源站（对象存储/文件服务器/P4 服务）
```

## 2. 数据采集（先取数再判断）

### 客户端侧

- 下载速度、失败错误码、重试次数。
- 分片日志：哪个分片失败、耗时分布。
- `curl -w` 分段计时（DNS/TCP/TLS/TTFB/下载速率）。

### 服务端侧

- 边缘节点：命中率、带宽、连接数、错误日志。
- 回源：回源量、回源成功率、回源耗时。
- 源站：负载、磁盘 IO、带宽、限流日志。

## 3. 分诊

```text
下载速度为 0 → 连接/网络/DNS 问题
速度低但稳定 → 带宽/限速/节点负载
时快时慢/中断 → 网络抖动、节点切换、分片问题
特定文件失败 → 缓存损坏、源站文件异常
发布后爆发 → 预热不足、回源雪崩、配置错误
```

## 4. 关键排查动作

### 4.1 验证「直连源站」

```bash
curl -o /dev/null -s -w 'ttfb:%{time_starttransfer} speed:%{speed_download}\n' https://<源站>/<大文件>
```

- 直连快 + CDN 慢 → 问题在 CDN 层（缓存策略/节点/调度）。
- 直连也慢 → 源站或网络链路问题。

### 4.2 验证 CDN 命中

```bash
curl -I <URL>   # 看缓存命中字段、Content-Length、Cache-Control
```

- 命中率低 → 缓存键/Header 问题、URL 带随机参数、调度分散。
- 命中但文件损坏 → 对比哈希，刷新缓存。

### 4.3 验证 Range/续传

```bash
curl -r 0-1048575 -o part1 <URL>   # 模拟分片下载
```

- 返回 206 + 正确 `Content-Range` 才是正确；返回 200 全量说明续传无效。

### 4.4 验证 DNS 调度

```bash
dig <域名>
```

- 解析是否就近、是否返回异常节点；多地解析对比。

## 5. 大包场景专项问题

| 问题 | 原因与对策 |
| --- | --- |
| 回源风暴 | 预热不足 + 大量未命中 → 错峰预热、加大缓存、分级缓存 |
| 源站带宽打满 | 回源量过大 → CDN 命中率提升、回源限速、扩容 |
| 单用户占满节点 | 无限速 → 单连接/单 IP 限速 |
| 分片下载失败 | Range 支持问题、分片大小不合理、网络抖动 → 分片重试 + 校验 |
| 下载到 99% 失败 | 末尾分片/校验失败 → 分片校验与重下、整包哈希验证 |
| 节点故障 | 调度未摘除 → 健康检查 + 主动摘除 |

## 6. 复盘输出

每次下载链路故障，输出：影响范围、时间线、瓶颈层（客户端/网络/CDN/回源/源站）、指标前后对比、改进项（监控、告警、预热策略、限速策略）。
