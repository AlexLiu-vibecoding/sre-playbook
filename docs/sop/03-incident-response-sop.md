# 故障响应与复盘 SOP

## 1. 故障分级

| 级别 | 定义 | 响应时限 | 通报 |
| --- | --- | --- | --- |
| P0 | 核心业务完全不可用/数据安全事件 | 立即 | 管理层 + 全群 |
| P1 | 大范围功能异常、有替代方案 | 15 分钟 | 业务方 + 相关团队 |
| P2 | 局部异常、影响有限 | 30 分钟 | 相关团队 |
| P3 | 低影响、可排期 | 工作时间 | 记录 |

## 2. 响应流程

```text
1. 确认：认领告警，判断级别
2. 止血：回滚/摘流量/切备用/重启——恢复优先
3. 定位：按排查手册逐段排除，建立时间线
4. 恢复确认：指标回归 + 用户复测
5. 降级/关闭：确认稳定后关闭告警通道
6. 复盘：24-48h 内输出报告
```

## 3. 角色分工

- 指挥（Incident Commander）：决策与协调，避免多头指挥。
- 一线：执行止血与定位。
- 二线：根因深入。
- 记录员：记录时间线与操作（供复盘）。
- 联络：对外（业务方）沟通影响与进展。

## 4. 止血动作库（按场景）

| 场景 | 止血动作 |
| --- | --- |
| 应用异常 | 回滚版本 / 重启实例 |
| 数据库慢 | 限流、Kill 慢会话、切只读 |
| 缓存故障 | 降级直连 DB（配合限流）、重启缓存 |
| CDN 故障 | 摘除异常节点、切备用域名/源站 |
| 网络故障 | 切 DNS、切线路、摘除故障 LB 后端 |
| 资源耗尽 | 扩容、清理、限流 |

## 5. 复盘规范

- 48 小时内完成，全程无指责（Blameless）。
- 直接原因 + 深层原因分开。
- 改进项带负责人与截止时间。
- 同类风险横向排查。
- 更新 Runbook 与告警，防止同类问题重演。

## 6. 复盘模板

```markdown
## 故障复盘
### 摘要（时间/级别/影响）
### 时间线
### 根因分析（直接/深层）
### 止血与恢复动作
### 改进项（负责人/截止/状态）
### 遗留风险
```
